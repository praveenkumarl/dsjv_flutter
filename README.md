# DSJV App 2.0

Flutter rewrite of the Android DSJV astrology WebView app.

## Quick start
1. Read SETUP.md
2. Read KEYS.md (CRITICAL: signing key determines ANDROID_ID)
3. See CHECKLIST.md before every release
4. flutter pub get && flutter run

## Package identity (do not change)
- applicationId: com.example.dsjvastroapp
- Auth endpoint: athenticate_mobile.php?key=<ANDROID_ID> (typo preserved)
- Base URL: https://pkastro.com/dsjv_home/
